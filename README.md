# FoodLink

## Project Overview
Food businesses throw away edible surplus food while charities lack supplies, and current communication relies on fragmented phone calls or messages. FoodLink provides a web-based platform to connect local food businesses with verified charities in real time.

## Objectives & Scope (Week 2 Updated)
- **Core Goal:** Let businesses post surplus food and verified charities find, reserve, and collect it.
- **In Scope (Version 1):** 
  - Role-based accounts (Donor, Charity, Admin).
  - Donation creation, search, and instant reservation.
  - Unique pickup code generation.
- **Out of Scope (Version 1):** 
  - Online payments, route optimization, AI recommendations, native mobile apps, and interactive maps (postponed to keep the prototype realistic).

## Target Users & Roles
- **Donors:** Restaurants, bakeries, and grocery stores posting edible surplus.
- **Charities / NGOs:** Organizations searching for and reserving donations.
- **Administrators:** Managing platform users and verifications.

## Planned Technologies
- **Frontend:** React.js (Web)
- **Backend:** Node.js with Express
- **Database:** PostgreSQL (with hashed passwords and secure access control)
