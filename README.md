# FoodLink

## Project Description
Food businesses throw away edible food while charities lack supplies. 
There is no simple tool connecting them.

## Objective
Develop a web/mobile platform where businesses publish surplus food 
and nearby associations reserve and collect it.

## Target Users
Donors (restaurants, bakeries), charities, volunteers, administrators.

## Planned Technologies
React, Node.js, PostgreSQL, Google Maps API, Firebase.

## Current Status
Week 1 - Project definition and research.
